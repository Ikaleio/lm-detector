检测网站 [lm.ikale.io](https://lm.ikale.io) 是纯前端应用：挑战生成、特征提取和排名都在浏览器中完成，参考库以静态文件下发。网页只检测和只读浏览参考库，不向参考库写入任何回复。API Key 只在发送请求时，按你选择的连接方式发给你填写的接口或转发代理，见[连接方式](./connection.mdx)。

## 取样方式

<Tabs items={['手动', 'API']}>
  <Tab value="手动">
    页面生成三道挑战。把每道挑战分别发给目标模型（例如在聊天界面中新开会话），再把回答粘贴回对应的样本框。适合只有聊天界面、没有 API Key 的情况。提示词和回复不会被翻译，切换界面语言也不会改变它们。
  </Tab>
  <Tab value="API">
    填写 API 配置后，页面按所选协议逐条或并行请求上游，边生成边显示回复。取样完成后可以自动开始验证。每条样本独立取样：一条取样时，其他样本仍可开始取样、停止、编辑或清空；样本卡的停止只中止该条，操作栏的停止中止全部。
  </Tab>
</Tabs>

还没有填入回复时，操作栏的“换一组提示词”一次替换三道挑战；已有回复时，“重新检测”替换挑战并清空回复。

## API 配置

| 字段 | 说明 |
| --- | --- |
| 接口地址 | Base URL 或完整端点。以协议端点（如 `/chat/completions`）结尾的地址原样使用，以 `/v1` 结尾的地址补上端点，其他地址会补上 `/v1` 和端点；基础路径不是 `/v1` 的接口请填完整端点 |
| 模型 | 请求中的模型名 |
| API Key | 默认隐藏，可以切换显示 |
| 推理强度 | 可留空，也可以填写上游支持的任意 `reasoning_effort` 值 |
| 接口协议 | Chat Completions、Responses 或 Messages |
| 服务等级 | Flex、默认、Fast 或 Ultrafast。默认不发送参数；Messages 发送 `speed` 并带 `anthropic-beta: fast-mode-2026-02-01` 头，Chat Completions 与 Responses 发送 `service_tier` |

配置下方的开关，除“分词器探测”外默认开启，另有一个并发请求数滑块：

- **流式输出**：使用 SSE 边生成边显示；关闭后等待完整的 JSON 响应。
- **并发请求数**：1 到 8，默认选中推荐值 3。取样和分词器探测各自最多同时发送这么多请求；设为 1 时逐个发送，耗时更长。
- **宽松模式**（推荐）：流式取样收到要求数量的完整有效整数后就停止；非流式回复超出要求时只取前 N 个。两者在界面上标为“已截断”。关闭后要求上游自然完整结束。
- **取样完成后自动验证**：三条样本都成功、且没有其他样本仍在取样时，自动计算结果。
- **分词器探测**（推荐）：默认关闭。开启后，取样时多发约 12 个短请求（最多 22 个），识别上游使用的分词器，结果只作参考，不改变排名；按次计费的接口会计入这些请求，见[分词器探测](./tokenizer.mdx)。

开关下方是“连接方式”：自动（默认）、直连、本站代理或自建 Worker，决定请求由浏览器直连接口还是经代理转发，见[连接方式](./connection.mdx)。

配置和密钥自动保存在浏览器的 localStorage 中，刷新或重新打开后恢复。配置菜单支持多份预设：重命名、新建、复制和删除；“保存”只在浏览器中确认当前配置，“导出”和“加载”在文件与浏览器之间转移配置，导出的文件包含 API Key 明文，不要发给别人或上传到网盘。“连接方式”是浏览器级设置，不属于任何一份预设。

## 阅读结果 [#reading-results]

三条回答都有效时，结果区按排名顺序列出参考库中的候选，每行显示一个置信度。置信度是参考库内的相对概率：全部候选合计 100%，不包含库外模型。校准与检测器不匹配时，只显示排名，不显示置信度。

排名和置信度只来自数字指纹。API 模式下，[分词器探测](./tokenizer.mdx)的结果作为参考信息单独显示在样本摘要条的第四项和分词器详情里；结果不等待探测完成，探测在结果旁继续进行。

第一候选的置信度低于 75% 时，页面提示“置信度不足”。只有一两条回答有效时，只显示排名，不显示置信度。

某条样本的最小有效数字不低于 200 时，页面把它标为分布异常，结果不可靠。这种分布由提示词引起，用原提示词重测仍会出现：API 模式下，“更换提示词并重测”为这些样本生成新的挑战，并沿用原取样参数立即重新取样；手动模式下，“更换提示词”只替换提示词并清空对应回复。其余样本保持不变。这一提示不参与评分。

<Callout type="warn" title="排名不是身份证明">
  库外模型也会得到一个“最像”的候选。测得同名结果可以作为支持证据，但不能独立证明身份；测得其他模型也不能直接断定模型被替换，因为某些模型的指纹天然接近。本站无法可靠检验间歇性替换模型的行为。
</Callout>

## 导出

- **PNG 图片**：在浏览器 Canvas 中按两倍像素密度生成，包含站名、日期、第一候选、前五项、有效样本数和限制说明，使用当前语言与主题；不包含 API Key、接口地址、所填模型 ID 或回复正文。
- **JSON**：候选列表与置信度；探测已结束时，另附分词器探测报告（判定、与所填模型的核对和每个请求的计数）。不含接口地址和 API Key。
- **样本库页面**：按模型浏览参考回复与各自的原始提示词，可以搜索、按家族筛选，并导出为 JSONL；导出前会去掉密钥和授权字段。
