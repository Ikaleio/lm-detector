## 仅供研究和参考

- 检测结果是参考库内的统计排序，不是身份认证。置信度只在已收录的模型之间比较，不在库中的模型也会得到一个“最像”的候选。
- 结果可能出错。模型版本、推理参数、提示词、渠道处理和参考库的覆盖范围都会改变结果。
- 测得同名模型不能证明接口真实；测得其他模型也不能证明接口造假或替换了模型，因为某些模型的指纹天然接近。
