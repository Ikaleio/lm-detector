## For research and reference only

- A result is a statistical ranking within the reference bank, not an identity check. Confidence compares only the models in the bank, and a model outside the bank still gets a "closest" candidate.
- Results can be wrong. Model versions, inference settings, prompts, channel processing, and the coverage of the bank all change the result.
- A matching name does not prove that an API is genuine. A different match does not prove that an API is fake or has substituted its model, because some models have similar fingerprints.
